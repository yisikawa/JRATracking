# JRA Tracking & Analysis App

[netkeiba.com](https://db.netkeiba.com) からレース結果を取得し、ベイズ推定を用いて騎手や競走馬の能力を分析・可視化するためのアプリケーションです。

## 機能

- **データ収集 (Data Collection)**:
  - **netkeiba.com** のレース結果ページからデータをスクレイピングします。
  - **日付指定**: 開催日を選ぶだけでその日の全レースを一括取得できます。
  - **レースID指定**: 12桁のレースID（例: `202601060112`）またはnetkeibaのURLを直接入力して個別取得もできます。
  - **一括収集**: 1〜5年分の土日レース結果を自動で一括取得します。取得済みのレースはスキップされるため、途中で止めて再開しても重複しません。
  - レース情報、競走馬（netkeibaの正式馬ID・性別・年齢）、騎手（netkeibaの騎手コード・氏名）、着順、タイム、オッズなどを取得し、ローカルデータベース (`jra_data.db`) に保存します。

- **分析・予測 (Analysis & Prediction)**:
  - 収集したデータを元に、Stan (CmdStanPy) を使用したベイズ推定モデルで学習を行います。
  - **勝利 + 3着以内を同時学習**: 1着フラグだけでなく3着以内フラグも尤度に加えることで、より多くの情報から能力を推定します。
  - **騎手能力 (beta_j)**: 各騎手の実力を数値化し、ランキング形式で表示します。
  - **馬能力 (beta_h)**: 各競走馬の実力を数値化し、ランキング形式で表示します。
  - 推定結果には不確実性（標準偏差や信用区間）も表示されます。
  - **勝率予測**: 騎手名と馬名を入力すると、学習済みモデルによる**勝率 (%)** と **3着内率 (%)** を出力します。学習データに含まれない騎手・馬は「平均能力」として自動処理されます。入力した騎手名はDBの騎手コードと照合して一致判定するため、名前の揺れに強い設計です。
  - 学習結果はセッション中キャッシュされ、ページ操作のたびに再学習されません。

- **今日のレース予測 (Today's Race Prediction)**:
  - 当日の出馬表を netkeiba から自動取得し、学習済みモデルで各馬の勝率・3着内率を予測します。
  - 開催日を選択して「レース一覧を取得」→ レースを選択 →「出馬表取得 → 予測実行」の3ステップで動作します。
  - 結果は勝率降順で表示され、学習データに存在しない騎手・馬には `⚠ 不明` が表示されます。
  - 出馬表データは取得後セッション内にキャッシュされ、同一レースの再予測は即時実行されます。

## 必要条件

- Python 3.8 以上
- 以下のPythonライブラリ（`requirements.txt`に含まれています）:
  - streamlit
  - pandas
  - requests
  - beautifulsoup4
  - sqlalchemy
  - cmdstanpy
  - plotly
- **CmdStan**: ベイズ推定を行うためのStanのコマンドラインインターフェース

## インストール手順

1. **ディレクトリの移動**:
   ```bash
   cd JRATracking
   ```

2. **依存ライブラリのインストール**:
   ```bash
   pip install -r requirements.txt
   ```

3. **CmdStanのインストール**:
   `cmdstanpy`を使用するために、CmdStan本体をインストールする必要があります。以下のコマンドを実行してください。
   ```bash
   install_cmdstan
   ```
   ※ 初回実行時にのみ必要です。詳細は [CmdStanPyのドキュメント](https://cmdstanpy.readthedocs.io/en/stable/installation.html) を参照してください。

## 使い方

1. **アプリケーションの起動**:
   ```bash
   streamlit run main.py
   ```

2. **ブラウザでアクセス**:
   通常は自動的にブラウザが開きますが、開かない場合は `http://localhost:8501` にアクセスしてください。

3. **データの収集**:
   - サイドバーのメニューから「データ収集」を選択します。
   - **日付指定タブ**: カレンダーで開催日を選び「一覧取得 → 全レース保存」をクリックすると、その日の全レースを自動取得します。
   - **レースID指定タブ**: 12桁のレースID（例: `202601060112`）またはnetkeibaのURL（例: `https://db.netkeiba.com/race/202601060112/`）を入力して個別取得します。

4. **分析の実行**:
   - サイドバーのメニューから「分析・予測」を選択します。
   - 「モデル学習 (データ更新)」ボタンをクリックします。
   - 学習が完了すると「能力ランキング」タブに騎手・馬のランキングが表示されます。

5. **勝率予測（手動入力）**:
   - 「分析・予測」→「勝率予測」タブを開きます。
   - 表に騎手名と馬名を入力し「予測実行」をクリックします。
   - 各出走馬の**勝率 (%)** と **3着内率 (%)** が降順で表示されます。
   - 学習データに含まれない名前は `⚠ 不明` と表示され、平均能力として計算されます。

6. **今日のレース予測（出馬表自動取得）**:
   - 先に「分析・予測」でモデル学習を完了させてください。
   - サイドバーから「今日のレース予測」を選択します。
   - 開催日を選んで「レース一覧を取得」をクリックすると、その日のJRAレースが一覧表示されます。
   - レースを選択して「出馬表取得 → 予測実行」をクリックすると、出馬表を自動取得して勝率・3着内率を予測します。
   - `⚠ 不明` が多い場合は、データ収集でより多くの日付のレース結果を集めてから再学習すると精度が向上します。
  - 予測には出馬表の騎手コードを使用するため、見習い騎手の記号（▲△☆◇）による誤認識は発生しません。

## ファイル構成

- `main.py`: アプリケーションのメインファイル (Streamlit)。
- `data/`
  - `scraper.py`: Webスクレイピングロジック。騎手コード取得・名前正規化を含む。
  - `database.py`: データベース定義と操作。Race / Horse / Jockey / Entry / Result の5テーブル構成。
- `analysis/`
  - `predictor.py`: Stanモデルのラッパー、学習・予測ロジック。
  - `jra_model.stan`: ベイズ推定モデルの定義ファイル。
- `requirements.txt`: 依存ライブラリ一覧。

## レースID の形式

レースIDは12桁の数字で、以下の構造になっています。

```
YYYY CC KK DD NN
2026 06 01 06 12
↑年  ↑開催場 ↑回 ↑日 ↑レース番号
```

**開催場コード:**

| コード | 開催場 | コード | 開催場 |
|:---:|---|:---:|---|
| 01 | 札幌 | 06 | 中山 |
| 02 | 函館 | 07 | 中京 |
| 03 | 福島 | 08 | 京都 |
| 04 | 新潟 | 09 | 阪神 |
| 05 | 東京 | 10 | 小倉 |

## 注意事項

- スクレイピングを行う際は、対象サイトの負荷にならないよう注意してください（本アプリにはリクエスト間に1秒の待機時間が設定されています）。
- サイトの構造変更により、スクレイピングが機能しなくなる可能性があります。
- **DBのマイグレーション**: 起動時に自動で新カラム・テーブルを追加します。ただし騎手IDの恩恵を完全に受けるには、DBを初期化してデータを再収集することを推奨します。
- **一括収集の時間目安**: 1年分 ≒ 20〜30分（リクエスト待機込み）。ブラウザのタブを閉じずそのままにしておけばローカル環境では途中切断は発生しません。

## CSVフォーマット (CSV Format)

インポート・エクスポート機能で使用するCSVファイルの各カラム仕様は以下の通りです。

### Races (レース情報)
| Column            | Description         | Example              |
| ----------------- | ------------------- | -------------------- |
| `id`              | レースID (Unique)    | `202601060101`       |
| `name`            | レース名            | `4歳以上1勝クラス`   |
| `date`            | 開催日 (YYYY-MM-DD) | `2026-01-05`         |
| `location`        | 開催場所            | `中山`               |
| `course_type`     | コース区分          | `芝`                 |
| `distance`        | 距離 (m)            | `2000`               |
| `weather`         | 天候                | `晴`                 |
| `track_condition` | 馬場状態            | `良`                 |

### Horses (競走馬)
| Column | Description                    | Example                    |
| ------ | ------------------------------ | -------------------------- |
| `id`   | netkeibaの馬ID (Unique)        | `2019104964`               |
| `name` | 馬名                           | `ドウデュース`             |
| `sex`  | 性別                           | `牡` / `牝` / `セ`        |
| `age`  | 年齢                           | `5`                        |
| `sire` | 父                             | `ハーツクライ`             |
| `dam`  | 母                             | `ダストアンドダイヤモンズ` |

### Jockeys (騎手)
| Column | Description                      | Example  |
| ------ | -------------------------------- | -------- |
| `id`   | netkeibaの騎手コード (Unique)    | `00666`  |
| `name` | 騎手名                           | `武豊`   |

### Entries (出走情報)
| Column           | Description                  | Example        |
| ---------------- | ---------------------------- | -------------- |
| `race_id`        | レースID                     | `202601060101` |
| `horse_id`       | 馬ID                         | `ドウデュース` |
| `jockey_id`      | 騎手コード (nullable)        | `00666`        |
| `bracket_number` | 枠番                         | `5`            |
| `horse_number`   | 馬番                         | `7`            |
| `jockey`         | 騎手名（表示用）             | `武豊`         |
| `trainer`        | 調教師                       | `友道康夫`     |
| `weight`         | 斤量                         | `58.0`         |

### Results (レース結果)
| Column         | Description | Example        |
| -------------- | ----------- | -------------- |
| `race_id`      | レースID    | `202601060101` |
| `horse_id`     | 馬ID        | `ドウデュース` |
| `rank`         | 着順        | `1`            |
| `time_seconds` | タイム (秒) | `118.5`        |
| `odds`         | オッズ      | `2.5`          |
